# ADR-0001: Модульный монолит на FastAPI + воркеры

**Status:** accepted · **Date:** 2026-08-30

## Context
ATS Jugo: 100k+ кандидатов, 200+ юзеров, 1000 RPS чтение, AI-native (скрининг/риски/вопросы/аналитика). Нужна модульность для параллельной разработки разными агентами.

## Decision
Модульный монолит на FastAPI (одна кодовая база, одна БД) + асинхронные воркеры (arq/Redis) для AI/фоновых задач. Жёсткие границы bounded contexts: `core/` (ядро), `platform/` (AI/EventBus), `modules/mX_*` (M1–M6). Модули общаются только через события (outbox → Redis Streams) и публичные фасады `core/*/public.py`. import-linter enforcing в CI.

## Alternatives
- Микросервисы — накладные расходы на этом масштабе, сложнее транзакционность/отладка.
- Чистый монолит без границ — нельзя раздавать модули агентам без риска.

## Consequences
+ Простая транзакционность, деплой, отладка; любой модуль выделяется в сервис без переписывания (контракты).
− Нужна дисциплина границ (import-linter, CODEOWNERS, миграции с префиксами).
